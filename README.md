# Apex – Intelligent Skill & Job Matching Platform

## Overview
**Apex** is a web-based intelligent career assistant that extracts technical skills from **GitHub, LinkedIn, and resumes**, maps them to target job roles, identifies skill gaps, and generates a **dependency-aware personalized learning roadmap**.
It also matches users with relevant job listings using **compatibility scoring** and **real-time market data**, enabling data-driven career decisions.

## Core Features
- Skill extraction and validation from GitHub, LinkedIn, and resumes  
- Role requirement mapping and skill gap analysis  
- Personalized dependency-aware learning roadmap generation  
- Job matching with compatibility scoring  
- Real-time job market data updates  
- Market demand visualization using heatmaps
